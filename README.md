# 🗳️ Face Vote System

## Overview
Face Vote System is a Python-based application that uses facial recognition technology to verify voter identity and enable secure electronic voting.

## Features
- Face recognition
- Voter authentication
- Secure voting process
- Prevents duplicate voting
- User-friendly interface

## Technologies Used
- Python
- OpenCV
- Face Recognition
- NumPy
- SQLite / MySQL

## Project Structure
- FACE_VOTE_PY.py
- Database
- Model Files
- Supporting Files
